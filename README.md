# broadsheet

Software for a newspaper-style blog/forum/whatever-you-want. You can check out the first project that uses broadsheet at [readopine.com](https://readopine.com).

## Development

This is purely a passion project and is just something we wanted to exist. I would recommend using a coding harness to interact with the repo for configuration and contribution, as all development was done using a coding harness and language models are more than capable of dealing with this repo.

## Making it yours

broadsheet is free; we just ask you keep its spirit. If you fix or improve something, please open an issue or a pull request. See `CONTRIBUTING.md`.
