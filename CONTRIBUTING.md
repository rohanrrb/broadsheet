# Contributing

broadsheet is free. Keep its spirit, and make it your own.

If you fix or improve something, please open an issue or a pull request here, so every paper gets it.

- `CLAUDE.md` describes how the software is put together and the rules it enforces.
- `npm test`, `npm run lint` and `npx tsc --noEmit` should pass.
- Contributions are accepted under the same licence as the project (AGPL 3.0).
